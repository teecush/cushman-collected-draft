# Shakespeare three-column play index

The Shakespeare landing page now places the play cards themselves in three parallel columns: Comedies, Tragedies, and Histories. Each category has a prominent heading directly above its own stack, and the former category jump-card row has been removed.

The play artwork keeps its original proportions at desktop and mobile widths. These small local images load immediately so every column has stable height before the user scrolls.

Checked at 1280, 390, and 320 pixel viewport widths, including the narrow mobile navigation and the full three-column play index.
